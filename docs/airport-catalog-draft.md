# 공항 카탈로그 초안 (3,244곳) — 검토용

항공편 입력의 출발·도착 공항 검색을 Google 대신 **우리 데이터**로 바꾸기 위한 초안입니다. **승인 전에는 DB에 넣지 않습니다.**
(이전 '171곳 초안'은 이 카탈로그에 흡수돼 지웠습니다 — 171곳 전부 이 안에 있습니다.)

- 원본 공항 목록: 사용자가 준 `travel_airports.csv`(3,244곳, 233개국, 중·대형 공항만 — 소형·헬리포트는 이미 빠져 있음). 이름·좌표·국가·IATA 코드.
- 도시·공항 이름(한국어·일본어·번체): **Wikidata**(무료 공개 데이터)에서 IATA 코드로 찾아 가져왔습니다. Google은 현재 키가 웹사이트 주소로만 쓰도록 잠겨 있어 스크립트에서 쓸 수 없었고, 우회하지 않았습니다.
- 시간대: 좌표에서 계산(`tz-lookup`) — 3,244곳 모두 값이 나옴.
- 검토용 전체 표: `docs/airport-catalog-draft.csv`(엑셀·넘버스로 열기), 원본: `supabase/data/airport_catalog.json`.

## 표시 이름 규칙
- 자동완성 한 줄: **도시(국가)** — 예: `도쿄(일본)`, 아래 작은 글씨로 `NRT · 나리타 국제공항`. 국가 이름은 앱 언어에 맞춰 브라우저가 번역(`Intl.DisplayNames`)해서 별도 데이터가 필요 없음.
- **도시는 공항이 '서비스하는 도시'**(Wikidata)로 잡았습니다. 그래서 나리타 공항 → `도쿄`(CSV의 '나리타'는 검색 별칭으로 남김), 쿠알라룸푸르 공항 → `쿠알라룸푸르`(CSV의 '세팡'은 별칭), 밀라노 말펜사 → `밀라노`. 서울특별시·도쿄도·오사카시처럼 행정구역 접미사가 붙은 이름은 `서울`·`도쿄`·`오사카`로 줄였습니다(행정구역 접미사를 떼는 규칙이라 드물게 어색한 곳이 있을 수 있음).
- 한 도시에 공항이 여러 개인 곳이 **97곳**(런던 3곳, 모스크바 4곳 등) — 같은 `도시(국가)` 줄이 공항 수만큼 나오고 작은 글씨로 구분합니다. 인천 직항이 있는 공항이 위로 옵니다.

## 이름이 채워진 정도
| | 도시 | 공항 |
|---|---|---|
| 한국어 | 2,551 / 3,244 (79%) | 978 (30%) |
| 일본어 | 2,824 (87%) | 2,912 (90%) |
| 번체 중국어 | 2,853 (88%) | 2,718 (84%) |

- **빈 곳은 영어 이름으로 보여 줍니다**(예: 한국어 이름이 없는 소도시 693곳은 영어 도시명). 인천 직항 169곳은 인천공항 API의 한국어 이름과 제가 만든 일본어·번체 이름으로 빈칸을 모두 채워 전부 채워져 있습니다.
- 한국어 공항 이름은 30%뿐이라 작은 글씨의 공항 이름은 한국어 UI에서 영어로 나오는 곳이 많습니다(도시 이름은 큰 글씨라 79%가 한국어).
- 도시 이름이 아예 없는 공항 15곳은 공항 이름으로 대신합니다.

## 알아 둘 점
- Wikidata 번역은 사람이 편집한 공개 데이터라 **틀린 이름이 섞여 있을 수 있습니다.** 훑어보시고 이상한 곳을 알려 주세요(CSV에서 찾아 고치면 됩니다).
- 번체 이름은 대만식 표기를 우선했지만 없으면 홍콩식·일반 중국어 표기로 대체됩니다.
- 좌표는 CSV 값을 소수 넷째 자리까지 그대로 썼습니다(Google 값과 수십 m 차이가 날 수 있음 — 날씨·지도에는 충분).
- 3,244곳 중 앱에 아직 없는 나라가 많습니다(`destinationRegions.ts`는 약 57개국). 이 카탈로그는 도시·여행지 목록과 별개이고, 항공편 공항 검색에만 씁니다.
