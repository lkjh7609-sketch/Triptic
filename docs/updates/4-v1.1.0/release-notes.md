# v1.1.0 공지 · 업데이트 내역 (게시용 초안)

- 종류: 업데이트 / 버전: 1.1.0 / 범위: 2026-10-04 ~ 10-05
- 제목: 1.1.0 업데이트 — 커뮤니티·공항 주차장·PDF 일정표 개편
- 게시: 운영 콘솔 '공지' 탭 → 본문(5,000자 이내)에 아래 내용을 붙여 넣기

```
■ 커뮤니티
· 커뮤니티가 회원 전용으로 변경되었습니다. 로그인 후 이용하실 수 있습니다.
· 자유게시판이 추가되었습니다. 도시 선택 없이 자유롭게 글을 작성할 수 있습니다.
· 글 제목 입력란이 추가되었고, 작성한 글을 수정할 수 있습니다. (도시·일정은 수정 불가)
· 글 상세 화면이 새롭게 바뀌었습니다. 사진 크게 보기, 좋아요·스크랩·공유, 댓글 답글·좋아요·이모지, 이전/다음 글 이동을 지원합니다.
· 모바일 게시판 화면을 더 가볍고 깔끔하게 개편했습니다. (작은 글씨, 오른쪽 작은 사진, 알약형 검색창)
· 글 목록을 작은 카드 형태로 변경했습니다. PC는 2열, 모바일은 가로 카드로 표시됩니다.
· 글·동행글 게시 후 뒤로 가기를 눌러도 작성 화면으로 돌아가지 않도록 수정했습니다.
· 글을 삭제하면 해당 글이 있던 게시판으로 이동합니다.
· 동행 모집글의 '모집 취소'가 '모집글 삭제'로 변경되었습니다.
· 내 글에 댓글·답글·좋아요가 달리면 종 알림으로 알려드립니다. 알림을 누르면 해당 댓글로 이동합니다.

■ 동행
· 같이 갈 사람 일치율에 나이대·성별이 반영됩니다. (도시 30·날짜 30·나이대 20·성별 20)
· 모집 인원이 '본인 제외 N명 남음'으로 표시됩니다.
· '내 동행모집' 버튼으로 내가 모집 중인 글만 모아볼 수 있습니다.
· 동행 화면에 나이대·성별이 표시됩니다. (선택 입력)

■ 공항
· 상단 메뉴에 '공항'이 추가되었습니다. 인천·김포·대구·김해·제주의 실시간 출·도착 전광판을 확인할 수 있습니다.
· 공항 주차장 평면도가 추가되었습니다. 혼잡도 색상, 남은 자리, 층별 상세 정보를 확인할 수 있습니다. (인천 T1/T2, 김포)

■ 여행 계획
· 항공편 '편명으로 불러오기'를 지원합니다. 편명과 날짜만 입력하면 시간·터미널·항공사가 자동으로 채워집니다.
· 밤새 도착하는 귀국편은 도착일을 계산하여 일정 종료일을 자동으로 연장합니다.
· 식사와 일정이 연동됩니다. 새로 정한 식당은 방문 시간을 물어 일정에 추가하며, 일정에서 삭제하면 식사 칸도 함께 줄어듭니다.
· 지도 위 선택 장소 카드를 접어 작은 버튼으로 둘 수 있습니다.
· 여행지 선택 방식이 대륙 → 국가 → 도시 순으로 변경되었습니다.

■ PDF 일정표
· 표지에 도시 사진과 예약 요약이 들어갑니다.
· 하루를 한 쪽으로 구성하며, 동선 지도와 타임라인, 하단 메모 칸이 포함됩니다.
· 숙소 주소·전화번호와 장소 간 이동 수단·시간이 표시됩니다.
· 빈 체크리스트와 경비 기록표가 포함됩니다. (4개 언어 지원)

■ 항공·호텔 (외국어 설정)
· Kayak 기반 항공·호텔 검색이 추가되었습니다. 현재 서비스 준비 중으로, 참고용으로만 이용해 주시기 바랍니다.

■ 알림·메일
· 가입 감사, 여행 3일 전 리마인더(오전 9시), 탈퇴 완료 안내 메일을 발송합니다. 리마인더는 출발 전 리마인더 설정을 따릅니다.

■ 설정·계정
· 프로필 사진을 변경할 수 있습니다.
· 성별·나이대(선택)를 '내 정보 변경'에서 수정할 수 있습니다.
· 무료 플랜의 여행 생성 사용량과 남은 개수를 확인할 수 있습니다.
· PC 설정 화면을 새 디자인으로 변경했습니다. (왼쪽 메뉴, 현재 기기 확인, Pro 안내)

■ 새 페이지
· 사용 가이드(/guide): 서류 업로드부터 공동 편집, 동행, PDF 내보내기까지 8단계로 안내합니다.
· 공지사항·업데이트(/notices): 새 소식은 종 알림으로도 안내됩니다.
· 여행기 작성 가이드 팝업이 추가되었습니다.

■ 안정성
· 아이폰에서 첫 접속 시 흰 화면이 나타나던 문제를 개선했습니다.
· 첫 방문 시 언어가 잘못 설정되던 문제를 수정했습니다.
· 아이폰 사파리에서 사진이 지나치게 큰 용량으로 업로드되던 문제를 수정했습니다.
· 홈 화면의 첫 로딩 속도를 개선했습니다.

■ 약관·방침 개정 (2026-10-05)
· 이용약관과 개인정보처리방침이 개정되었습니다. 커뮤니티 회원 전용 전환, 나이대·성별(선택) 수집, 접속 정보 기록, 알림 메일 발송(Resend)에 관한 내용이 반영되었습니다.
```
